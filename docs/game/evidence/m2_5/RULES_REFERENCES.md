Ruleset utilisé dans le noyau : One Piece Card Game Comprehensive Rules v1.2.1, 28 août 2026 (`rulesVersion: 1.2.1`).

| Ordre automatique / Trigger | §8-6 | Scheduler historique préservé; nouveau timing de combat et Trigger non implémentés. |
